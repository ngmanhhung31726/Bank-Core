# 🏦 BANK CORE

**Dự án:** Ngân hàng lõi thu nhỏ (Mini Core Banking System)

## Thông tin đồ án

- **Nhóm:** Nhóm 5
- **Môn học:** Đồ án Cơ sở dữ liệu
- **Đề tài:** Xây dựng hệ thống ngân hàng lõi thu nhỏ.

## Stack Ứng Dụng

- Oracle Database Free
- **&#x20;Java (Spring JDBC)**
- PL/SQL
- Liquibase

## Trọng tâm CSDL

- PL/SQL Packages
- Giao dịch ACID
- Bút toán kép
- Kiểm toán dữ liệu&#x20;

## Chức năng chính

- Quản lý khách hàng và tài khoản.
- Nạp tiền, rút tiền và chuyển khoản.
- Quản lý giao dịch và số dư.
- Hạch toán kế toán.
- Lưu vết và kiểm toán giao dịch.
